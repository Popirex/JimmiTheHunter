# Jimmy The Hunter

A **2D platformer** written in **C** using the [raylib](https://www.raylib.com/) library.
Control Jimmy, a hunter who runs, jumps and shoots through a tile-based world.


## Controls

| Key | Action |
|-----|--------|
| `D` | Move right |
| `A` | Move left |
| `Space` | Jump |
| `Left click` | Shoot |

## Build and run

### Requirements

- A C compiler (`gcc` or `clang`)
- [raylib](https://github.com/raysan5/raylib/wiki) installed
- `make`

### Build

```bash
git clone https://github.com/Popirex/JimmiTheHunter.git
cd JimmiTheHunter
make
```

Run the game **from the project's root folder**, since the resource paths (`rsc/...`) are relative.
